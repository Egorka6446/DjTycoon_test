# AFTERHOURS · DJ Tycoon

Небольшая браузерная tycoon-игра про диджея: записывай лупы, собирай треки, играй ритм-сеты, открывай новые площадки и развивай собственный клуб. Игра работает без рекламы, аккаунтов и платных ограничений.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Vite. Для production-проверки:

```bash
npm test
npm run build
```

Прогресс сохраняется в `localStorage`. В настройках можно скачать JSON-резервную копию и загрузить её позже. Кнопка «Включить звук» запускает встроенный Web Audio саундтрек; внешние музыкальные сервисы не нужны.
